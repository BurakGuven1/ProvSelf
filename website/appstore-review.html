ProvSelf iOS Release Notes for Review Team

Core User Flow

  • User creates a daily or weekly challenge.
  • User stakes in-app virtual tokens for accountability.
  • User verifies progress via photo or Apple Health (based on challenge policy).
  • Challenge settles to success/fail according to in-app rules.

Important Clarifications

  • Tokens are virtual in-app units and not real currency.
  • No real-money payout to users.
  • Digital purchases use Apple In-App Purchase where applicable.
