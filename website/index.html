Token Logic

Simple and transparent: verify consistently to keep your token value.

  1. Buy token packs in-app.
  2. Stake tokens when starting a challenge.
  3. Complete daily or weekly verification.
  4. If successful, principal tokens are returned based on challenge rules.
  5. If you miss verification days, penalties apply and token return decreases.

Tokens are in-app virtual units for commitment mechanics and are not cash, securities, or transferable assets.
